# code-changelog

此 Skill 用于自动提取 Git 提交记录并整理成结构化的中文更新日志。

## 工作流程

1. **提取提交记录**: 运行 skill 目录下的 `scripts/get_commits.sh`（即 `.agents/skills/code-changelog/scripts/get_commits.sh`）获取最新两个 Tag 之间的提交记录。如果没有足够的 Tag，则获取最近的提交。
2. **过滤与分类**: 
    - 忽略 CI/CD 配置、仅文档（docs）、纯代码重构（refactor）且不影响功能的提交。
    - 将剩余提交分类为：
        - **[新功能]**: 增加了新特性或功能。
        - **[体验优化]**: 改进了现有功能的 UI、交互或性能。
        - **[修复]**: 修复了已知问题或漏洞。
3. **编写小结**: 
    - 使用中文。
    - 语言简洁、专业、面向最终用户。
    - 包含版本号信息（最新的 Tag 名称）。

## 使用示例

当用户说“帮我生成更新日志”或“整理一下最新变动”时，触发此流程。

### 输出格式模版

所有输出必须为纯文本，不使用任何 Markdown 标记（含 `#` 标题、`**` 粗体、`-`/`*` 列表符号、反引号代码块、emoji 等）。分类标签 `[新功能]`/`[体验优化]`/`[修复]` 为约定字面量，保留方括号原文输出。各分类之间以空行分隔，分类下每行以连字符 `-` 开头作为条目符号（这是模版规定的格式，不属于 Markdown 列表符号）。

```
更新小结 (版本号)

[新功能]
- 功能点 A 描述...

[体验优化]
- 优化点 B 描述...

[修复]
- 修复问题 C 描述...
```
