# LLM models are configurable, constrained by capability tier not vendor

The first-stage (cheap, fast, filing-structure-aware, JSON-schema-compliant) and second-stage (strong reasoning, nuanced writing, understands retail-investor cognitive biases, consistent multi-dimensional scoring) models are selected via worker configuration, not hardcoded. Prompts are written in a vendor-neutral structured style and avoid proprietary features (e.g. Anthropic XML tags, OpenAI-specific function-calling shapes) so either tier can be swapped by changing a config value. The trade-off is forgoing vendor-specific prompt optimizations and features in exchange for portability and the ability to reroute if a provider raises prices, rate-limits, or degrades. The capability constraints per tier are the real contract; the model name is an instance.
